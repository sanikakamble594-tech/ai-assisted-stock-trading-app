# 📈 AI Stock Trading App - Built with Emergent

An intelligent AI-powered stock trading analysis and prediction platform, completely built using prompts on **Emergent AI**.

> This entire application is built without writing manual code - 100% generated via AI prompts on Emergent.


### ✨ Features

- **Real-time Stock Analysis:** Live stock prices and charts with TradingView integration
- **AI Prediction Engine:** AI predicts next day/week trend (Bullish / Bearish)
- **Smart Buy/Sell Signals:** AI gives BUY, SELL, HOLD signals based on technical analysis
- **Portfolio Tracker:** Track your virtual investments and P&L
- **Market News & Sentiment:** AI analyzes latest market news sentiment
- **Interactive Dashboard:** Clean, modern and responsive UI
- **Risk Management:** Stop-loss and target suggestions by AI

### 🧠 How It Works

This app uses AI to analyze:
1.  Technical Indicators (RSI, MACD, Moving Averages)
2.  Historical Price Patterns
3.  Market News Sentiment
4.  Volume Analysis

And then gives a final trading recommendation.
